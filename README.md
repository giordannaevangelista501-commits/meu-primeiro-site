# Autopeças – Gestão Integrada

Protótipo navegável de um sistema ERP para lojas de autopeças, feito com **HTML e CSS** na atividade "Meu Primeiro Site" do curso de Análise e Desenvolvimento de Sistemas – UniGoiás.

🔗 **Site publicado:** https://giordannaevangelista501-commits.github.io/meu-primeiro-site/

## Páginas
- `index.html` – Tela de login (página inicial)
- `painel.html` – Painel com as abas Painel, Vendas, Estoque, Clientes e Financeiro
- `contato.html` – Contato, equipe e "Sobre o sistema"

## Tecnologias
HTML, CSS, Git, GitHub, GitHub Pages, VS Code (Live Server e Prettier), Figma e Canva.

## Como funciona a simulação
O site não usa JavaScript nem banco de dados. As abas e a demonstração de venda (cadastrar produto → cadastrar cliente → finalizar venda) funcionam só com CSS. Os dados são fictícios e nada é salvo.
